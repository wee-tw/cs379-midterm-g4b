# FINN v0.10.1 resource-estimate audit dataset

These are the FINN-generated nodes of an MLPerf Tiny ResNet-8 (Brevitas QAT, per-group bit widths 2/4/8). For each node there is FINN's own resource estimate next to the synthesis results.

Scripts are in `code/`. Every number in these files is a synthesis result or an estimate, not a board measurement.

## Settings

- **Part:** xc7z020clg400-1 (PYNQ-Z2).
- **Vivado:** `synth_design -mode out_of_context`.
- **Units:** LUT is Slice LUTs (logic plus memory). BRAM18 is 2 × Block RAM tiles.
- **FINN version:** the official v0.10.1 tag (9d29968), unmodified.

## Caveats

- **MVAU_rtl BRAM is not comparable between the two sources.** FINN's MVAU_rtl BRAM estimate counts the weight memory, which sits outside the synthesized unit. The synthesized unit's BRAM is the input replay buffer.
- **Vivado power values are rough.** They are vectorless estimates (default 12.5% toggle rate). Against board measurements, Vivado power is reported to be about 20% off (PowerGear, DATE 2022).
- **Timing is post-synthesis, out of context.** Routing usually adds delay, so the periods are optimistic. Folded MVAU_hls (SF > 1) and MVAU_rtl get slower as SIMD grows: the v0.10.1 RTL cores add the DSP lanes in an unpipelined LUT tree (about 1.2 ns per doubling of SIMD); unfolded MVAU_hls (SF = 1) stayed under 7.63 ns at every width.
