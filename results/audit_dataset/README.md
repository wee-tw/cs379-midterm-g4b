# FINN v0.10.1 resource-estimate audit dataset

These are the FINN-generated nodes of an MLPerf Tiny ResNet-8 (Brevitas QAT, per-group bit widths 2/4/8). For each node there is FINN's own resource estimate next to the synthesis results.

Scripts are in `code/`. Every number in these files is a synthesis result or an estimate, not a board measurement.

| File | Rows | Content | Generated by |
|---|---|---|---|
| `rtl_nodes.csv` | 159 | 53 MVAU_rtl, 49 Thresholding_rtl, 47 ConvolutionInputGenerator_rtl and 10 FMPadding_rtl. Columns: FINN estimate (`finn_*`), Yosys 0.70 `synth_xilinx` (`yosys_*`), Vivado 2022.2 out of context (`vivado_*`) | `audit_rtl_ops.py` |
| `hls_nodes.csv` | 156 | MVAU_hls with internal thresholds, each in three `ram_style_thresholds` styles. Columns: FINN estimate, Vitis HLS 2022.2 csynth estimate (`hls_csynth_*`), and synthesis through `export_design -flow syn` (`synth_*`) | `audit_hls_thresholds.py` |
| `thr_triggers.csv` | 98 | Thresholding_rtl with `depth_trigger_bram` set to 2^30 and to 1024. Columns: our threshold-memory model (`model_*`) and Vivado | `thr_trigger_vivado.py` (scratchpad) |
| `designs.csv` | 584 | Every node and weight streamer of 11 synthesized design builds (9 distinct designs; `set` names the batch: `vd`, `vd2`, `vd3`, `vd4`). Columns: the cost model's prediction (`pred_*`; v1 calibration for `vd` and `vd2`, v2.1 for `vd3` and `vd4`), synthesis, and Vivado vectorless dynamic power at the design clock | `verify_designs.py` |

## Settings

- **Part:** xc7z020clg400-1 (PYNQ-Z2).
- **Vivado:** `synth_design -mode out_of_context`.
- **Units:** LUT is Slice LUTs (logic plus memory). BRAM18 is 2 × Block RAM tiles.
- **FINN version:** the official v0.10.1 tag (9d29968), unmodified.

## Caveats

- **MVAU_rtl BRAM is not comparable between the two sources.** FINN's MVAU_rtl BRAM estimate counts the weight memory, which sits outside the synthesized unit. The synthesized unit's BRAM is the input replay buffer.
- **Vivado power values are rough.** They are vectorless estimates (default 12.5% toggle rate). Against board measurements, Vivado power is reported to be about 20% off (PowerGear, DATE 2022).
